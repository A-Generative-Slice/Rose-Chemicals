## 🌟 Architecture & Capabilities

### 1. Web Platform (`/app` & `/src`)
- **Modern Minimalist Storefront**: High-performance animated catalog for chemical formulations, industrial detergents, and specialty solutions.
- **Factory Production Management**: Batch scheduling, godown inventory levels, and real-time order tracking.
- **Automated Invoicing**: Razorpay payment integration with automated PDF invoice dispatch.

### 2. Conversational WhatsApp AI Assistant (`/whatsapp-bot`)
- **Multilingual Customer Support**: Powered by Sarvam AI voice and text models for Tamil and English dialect recognition.
- **Automated Catalog Inquiries**: Instant product specs, pricing, and MSDS safety data lookups.
- **Conversational Re-Ordering**: Existing clients can re-order chemical drums directly via conversational WhatsApp messages.

## 🚀 Getting Started

```bash
# Install storefront dependencies
npm install

# Run development server
npm run dev

# Launch WhatsApp Bot
cd whatsapp-bot
npm install
npm start
```
