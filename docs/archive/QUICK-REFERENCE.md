## 🔒 Setup SSL (HTTPS) - Important!

After deployment, run this on the VPS to enable HTTPS:

```bash
ssh root@72.60.218.57

# Install SSL certificate
sudo certbot --nginx -d rosechemical.in -d www.rosechemical.in

# Follow the prompts:
# - Enter email: your-email@example.com
# - Agree to terms: Y
# - Share email: N (optional)
# - Redirect HTTP to HTTPS: 2 (Yes, redirect)
```

This will:
- Install free SSL certificate from Let's Encrypt
- Auto-configure nginx for HTTPS
- Auto-renew certificate every 90 days
- Redirect all HTTP to HTTPS

## 🔍 Troubleshooting

### Site not loading?
```bash
# Check if services are running
pm2 status
sudo systemctl status nginx

# Restart everything
pm2 restart all
sudo systemctl restart nginx
```

### API not working?
```bash
# Check backend logs
pm2 logs rose-backend

# Check if MongoDB is running
sudo systemctl status mongodb
sudo systemctl restart mongodb
```

### Port conflicts?
```bash
# Check what's using ports
sudo lsof -i :3000
sudo lsof -i :5000

# Kill and restart
pm2 delete all
cd /var/www/rose-chemicals
pm2 start ecosystem.config.js --env production
```

### Need to start fresh?
```bash
# Stop everything
pm2 delete all
sudo systemctl stop nginx

# Re-run deployment
cd /var/www/rose-chemicals
./deploy-to-vps.sh
```
